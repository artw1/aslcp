ASLCP

A modern web control panel for AllStarLink 3 nodes: connect, monitor and manage favorites with live status. For Debian 12 (bookworm), Debian 13 (trixie) and Raspberry Pi OS on arm64, armhf and amd64.

Latest release: 1.2.3. Latest beta: 1.2.3 (same as stable).

Documentation, screenshots and bug reports on GitHub

Install

curl -fsSL https://artw1.github.io/aslcp/install.sh | sudo sh

On a freshly flashed ASL3 card, wait for the first-boot setup and its reboot (20-30 minutes) before installing. The installer checks this and tells you if it is not done yet.

The installer prints a one-time setup link at the end. Open it to create the administrator or to restore a backup from an existing node. sudo aslcp admin setup-code shows the code again.

Web port

The web interface listens on port 8080 by default. To pick another port, set ASLCP_PORT (1-65535) with the install command:

curl -fsSL https://artw1.github.io/aslcp/install.sh | sudo ASLCP_PORT=8181 sh

To change it later, run the same command again, or edit listen in /etc/aslcp/aslcp.conf (for example listen = :8181) and run sudo systemctl restart aslcp. The installer warns if another program already uses the port. If firewalld is running, the installer and the package open the configured port for you. With another firewall (ufw, nftables, a router) open the TCP port yourself, and if you edit listen by hand with firewalld, open the new port too.

DVSwitch

To install DVSwitch as well, set ASLCP_DVSWITCH=1 (yes and true work too):

curl -fsSL https://artw1.github.io/aslcp/install.sh | sudo ASLCP_DVSWITCH=1 sh

It can be combined with ASLCP_PORT:

curl -fsSL https://artw1.github.io/aslcp/install.sh | sudo ASLCP_DVSWITCH=1 ASLCP_PORT=8181 sh

After ASLCP is running, the installer runs aslcp dvswitch install (the same install as the DVSwitch page; it takes a few minutes). If it fails the installer still finishes, and you can retry with sudo aslcp dvswitch install.

Manual setup

sudo curl -fsSL -o /usr/share/keyrings/aslcp-archive-keyring.gpg https://artw1.github.io/aslcp/aslcp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/aslcp-archive-keyring.gpg] https://artw1.github.io/aslcp stable main" | sudo tee /etc/apt/sources.list.d/aslcp.list
sudo apt update && sudo apt install aslcp

Beta channel

Every new version is published to the beta suite as soon as it is built. It becomes a release (suite stable) when it is promoted after testing: the same package, not a rebuild. The beta suite also carries every release, so beta users are never behind. Betas may be less stable. To use it, put beta instead of stable in the line above, or install with curl -fsSL https://artw1.github.io/aslcp/install.sh | sudo ASLCP_CHANNEL=beta sh, or switch in Settings → Updates in the web UI (the same setting: it changes the suite in /etc/apt/sources.list.d/aslcp.list). Going back to stable does not downgrade: the node stays on the installed version until a release newer than it is promoted.

Later updates: Settings → Updates in the web UI, or sudo apt update && sudo apt upgrade.
